# Contributing

Bit is a **V1 preview**. Issues and PRs are welcome.

1. Read [README.md](README.md) and [docs/LIMITATIONS.md](docs/LIMITATIONS.md).
2. `npm install` (repo root and `web/`), then `npm test`.
3. Keep the Excel add-in on **Vite 6** (Node 20.17 does not run Vite 8).
4. Do not commit `data/`, `.env`, or OneDrive project folders.
5. UI copy stays product language: Save version, Scenario, What changed, Make this Main — not commit/PR/merge.

The collaboration model is **same project, two workbooks**. Do not add Excel co-authoring of one file as the collab path.
