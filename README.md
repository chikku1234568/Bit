# Bit — M1 Xlsx Bridge

Version control for Excel. This milestone (**M1**) delivers the parse/write bridge between `.xlsx` files and Bit’s canonical workbook snapshot.

## Install

```bash
npm install
```

Requires Node.js 18+.

## Test

```bash
npm test
```

Round-trip tests build an FP&A-style budget workbook (values, formulas, bold/fill/numFmt), write → parse → write → parse, and assert tracked fields survive.

## Round-trip CLI

```bash
npm run roundtrip -- path/to/file.xlsx
```

Prints sheet/cell counts and writes `path/to/file.roundtrip.xlsx` next to the input.

Example with a fixture generated by tests:

```bash
npm test   # writes fixtures/sample-budget.xlsx
npm run roundtrip -- fixtures/sample-budget.xlsx
```

## Fidelity bar (tracked)

- Sheet names and order
- Cell values (`v`) and formulas (`f`)
- Basic formatting: bold, italic, fill colour, font colour, number format

## Not tracked (V0)

- Charts, pivots, images, form controls
- Data validation, conditional formatting rules
- Named ranges, VBA / macros, external links
- Column widths, row heights, merged cells (beyond address-stable cells)
- Calculated cache as source of truth (formula is authoritative; cached value optional)

## Layout

```
src/xlsx/          # bridge only — kept separate from future merge module
  types.ts         # Cell, Sheet, WorkbookSnapshot
  parse.ts         # parseXlsx(buffer | path) → WorkbookSnapshot
  write.ts         # writeXlsx(snapshot) → Buffer
  index.ts
  roundtrip.test.ts
scripts/roundtrip.ts
fixtures/          # sample budget-style workbook (generated by tests)
```
